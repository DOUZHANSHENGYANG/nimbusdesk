03 · 落地前必须知道的四件事

  • 窗口尺寸归 Rust，CSS 过渡不了。 胶囊 44 高、卡片 660×500，切换时 set_size 一次到位（或 2–3 帧插值）；CSS 只做圆角／内边距／内容 stagger，别用 transform 假装变宽 —— 会糊。
  • 透明窗口里 backdrop-filter 糊不到桌面。 本稿能糊是因为壁纸和卡片在同一个文档里。真机要么走 DWM 材质（window-vibrancy 或 DWMWA_SYSTEMBACKDROP_TYPE），要么退回「高不透明度实底 + 轻 blur」。假糊在 Mica 环境里会变灰框（dsh-orb #78 就是这个）。
  • 顶部居中 + 置顶会压住最大化窗口的标题栏。 建议默认距顶 12px，设置里给三档：贴顶 / 跟随焦点窗口下沿 / 只在没有最大化窗口时显示。
  • 对比度与双语是闸门。 玻璃叠层上正文必须 ≥4.5:1（新的 --glass 组合要纳入 npm run check:contrast）；五个 tab 的名称／占位／空态全部 zh+en 同时进 src/lib/i18n.ts。
