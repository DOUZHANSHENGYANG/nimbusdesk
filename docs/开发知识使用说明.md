# 开发知识与快捷收集

## 绑定知识库

在“设置 → 开发知识”选择包含 `.obsidian` 的文件夹，也可从左侧“开发知识”页面绑定。绑定不会移动原有文件；应用数据目录、文件收藏根目录与知识库彼此独立。

索引覆盖 `01-技术/`、`02-工作/`、`04-资源收藏/`、`08-收件箱/`，跳过隐藏目录、技能和依赖目录。支持标题与正文全文检索。外部修改后点击刷新，或重新聚焦页面刷新。

## 快速收集

托盘“快速收集”、开发知识页按钮或默认快捷键 `Ctrl+Alt+Space` 打开独立置顶面板。设置中可更换组合键；注册失败会保留旧组合键。

- 输入文字、代码、报错、网址，或粘贴、拖入、选择图片。
- 标题留空时根据正文生成；图片保存名称可编辑，不改外部原图。
- 项目目录、仓库地址、来源说明均可临时填写。
- `Ctrl+Enter` 保存；`Esc` 或关闭按钮等草稿落盘后隐藏。
- 草稿按 vault 保存在本机，重启可恢复；已保存材料才会跟随 vault 移动。
- 多窗口草稿冲突可先另存本地输入为新条目，再读取最新草稿。

```text
08-收件箱/工作台/<条目ID>/
  条目.md              正文、项目、来源及图片 WikiLink
  条目.json            元数据、附件路径及归档去向
assets/images/工作台/<条目ID>/
  <图片名称>-<序号>-<短ID>.png
```

支持 PNG、JPEG、WebP、GIF，单张最多 10 MB，单条最多 30 MB、10 张。图片先保存本地，只有主动勾选发送图片时才上传 AI。

## 整理与归档

勾选收件箱材料，选择手动整理或 AI 建议。多条可合并为一份笔记；检查标题、正文、标签及分类后确认归档。

| 类型 | 目录 |
|---|---|
| 开发经验 | `02-工作/开发经验/` |
| 开发配方 | `02-工作/开发配方/` |
| 收藏资料 | `04-资源收藏/` |

原始材料保留，整理笔记附来源与图片 WikiLink；条目元数据记录归档目标。已归档材料从待整理列表移出，可以在“全部”回查。程序拒绝静默覆盖；原文被外部修改时需刷新并重新整理。

AI 输出是待确认建议，不能证明问题已解决。请在正文记录适用环境、验证方法、结果及时间。

开发配方用 `{{端口}}` 等占位符，提供参数输入、替换预览和复制，不执行命令。

## 自定义 AI 提供商

在“设置 → AI”填写提供商名称、Base URL（通常到 `/v1`）、模型名及可选 Key。图片模型需开启图片能力，可分别选择默认文本和图片提供商。填写/修改 Key 后先保存，再测试连接。无鉴权本地服务可不填 Key；整理采用非流式请求。

新 Key 存在当前 Windows 用户的系统凭据管理器，不进入提供商 JSON。换电脑后需重新输入。旧资讯配置可显式迁移，成功后移除旧配置与已知历史备份中的明文 Key；失败保留旧配置供重试。迁移前，旧资讯调用保持兼容。

## 文件与 Git

工作台应用备份不包含知识库正文与图片，继续使用已有知识库 Git/备份流程。应用不会自动提交其他文件或推送。正式归档目录首次保存时创建；保存失败不清空输入，未完成事务保留暂存/恢复记录。
