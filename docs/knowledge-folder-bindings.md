# 开发知识的管理范围

在「设置 → 开发知识 → 知识分类文件夹」选择或输入当前 Obsidian 知识库内的相对目录，点击「保存文件夹绑定」。每个知识库分别保存一份配置，存入工作台 SQLite；切换知识库不会套用另一份库的绑定。

默认沿用原来的目录：

| 分类 | 默认文件夹 |
| --- | --- |
| 开发经验 | `02-工作/开发经验` |
| 开发配方 | `02-工作/开发配方` |
| 资源收藏 | `04-资源收藏` |

工作台只扫描收件箱 `08-收件箱/` 和三个绑定目录。新收集材料仍保存在 `08-收件箱/工作台/<条目ID>/`，图片仍使用 `assets/images/工作台/` 和 WikiLink。其他笔记不进入工作台的列表、搜索、标签统计或分类页，也不会自动改写。

三个分类目录需要互不重叠，可以自定义位置与名称；路径不能越出当前库，也不能指向链接、隐藏配置或附件目录。绑定不会搬动文件，缺失目录在归档时创建。扫描分类、AI 整理目标预览与实际归档使用同一份配置。改绑后，原先归档的文件和材料追溯记录继续保留。

标签区默认显示三行，点击「展开全部…标签」后在区域内滚动，点击「收起标签」恢复。已选标签单独显示，可一键清除。查找标签输入框在桌面宽屏下使用 384px 的搜索区域。

验证：`npm run verify`、`npm run build`；本次浏览器夹具包含 320 个标签，原生验证使用独立临时库，检查配置存储、范围切换与自定义归档，不写真实知识库。
