## 看过但决定不改

- **首页三处入口重叠**（快速跳转 / 页签 / 卡片底部链接）：分别对应模块入口、数据视图、单卡出口，删任一条都少一条路径。
- **项目页与 GitHub 页的「列表 + 抽屉」不同构**：项目页多了迭代与看板维度，强行统一会拖垮其中一边。
- **资讯行内编辑/删除只在悬停时出现**：触屏不可达，但「管理订阅源」里有同一组动作，键盘也能 Tab 到。
- **映射盒与新建收纳盒的图标**：墙上已经是 `FolderOpen / Archive / FolderSymlink` 三套图标 + 三套 accent（`page.tsx` 的 `BOX_KIND_ICON` / `BOX_KIND_COLOR`），不需要再拆。

## 仍未做

- ~~从不打开盒子的墙面把条目拖进盒子~~：已补——墙上方块预览里的图标可以直接拖到另一个方块（换盒）或拖到墙面空白（移出所有盒子）；Windows 桌面栅栏窗口之间的拖拽仍是另一套窗口级实现，未动。
- **「拖进盒子后原处还在」若发生在文件（非网址）上**：当前代码会把记录改到目标盒并从原盒消失；未选中分类时列表本来就是「全部条目」，所以仍会看到它——需要一次真机复现确认是哪种视图。

## 第二轮：四个子代理的分功能对抗审查

通道恢复后按功能派了四个子代理（首页/工具/画布、文件收纳、资讯、项目+GitHub），各读 impeccable 的 SKILL + craft-floor + critique，只读代码、输出「严重度 / 结论 / 文件:行号 / 改法」。以下为采纳与拒绝。

### 采纳

| 来源 | 问题 | 处理 |
| --- | --- | --- |
| 首页 | 绿色/琥珀写死在组件里，绕过 token 与对比度门禁 | 改用 `bg-success` / `text-warning` |
| 首页 | 四张卡重量相等，主卡没有层级 | `DashboardCard` 加 `titleClassName`，计划卡标题加重 |
| 首页 | 八个复选框共用一个 aria-label | 新 key `home.toggleDoneFor`（带标题） |
| 首页 | 快速跳转里常驻「待整理」静态 hint 像状态 | 去掉该 hint |
| 工具/文件/画布 | 去掉标题后页面没有 level-1 标题 | 补 `sr-only` 的 h1（视觉上仍不重复） |
| 侧栏 | 导航按钮没有 focus-visible，键盘退回浏览器描边 | 补焦点环 |
| 文件收纳 | 拖到「新建收纳盒」卡上被当成"移出所有盒子"，条目当场消失 | 改判：打开新建表单并把条目预置进去 |
| 文件收纳 | 「桌面」落点写 `categoryId: ""`，条目在文件页无处可看 | 改为落到自动创建的「桌面」盒，仍可见可找 |

| 资讯 | 跨组拖动排序是假的（按全局下标换位） | 只允许同组内换位 |
| 资讯 | 排序只有鼠标一条路 | 补 Alt+↑/↓ 键盘移位 |
| 资讯 | 管理入口只在 `hidden md:flex` 的左栏里 | 工具栏加「管理订阅源」，窄屏可达 |

### 拒绝或推迟

- **首页「快速跳转」与侧栏重复**：右上角这列承担的是"带读数的去处"，与侧栏的纯导航不同；删掉会让首屏失去唯一的状态入口。
- **资讯左栏行内编辑/删除整组撤掉、只留管理弹窗**：用户明确要过"悬停出编辑删除"，且管理弹窗在左侧栏外也能进；两条路径保留，只修了触屏不可见却可点的问题。
- **侧栏 `aria-expanded` 语义与 24px 展开热区**：涉及侧栏折叠模型，改动面大于本次批次，留待单独一轮。
- **画布 iframe 的 loading/error 态**：需要新的状态机与夹具，未在本批处理。
- **文件移动的撤销栈**：需要给 `moveItemsToBox` 接 history，且与存储盒的磁盘搬运耦合，留待单独一轮。
- **GitHub 抽屉在宽屏变成静态第三列**：需要给面板加容器查询与布局切换，未在本批处理。
- **GitHub 空态加动作按钮 / 缺失条目移到顶部**：已记录，未在本批处理。
