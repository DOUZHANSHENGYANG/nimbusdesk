# 计划管理：任务详情面板

大纲视图里的任务行不再就地变成编辑框。点标题，面板浮在这一行的上方，
改完关掉就行 —— 行本身的高度、位置全程不变。

## 为什么改

旧实现是「点标题 → 这一行长高成编辑框」，一保存就重排：下方所有行整体上移，
而 pointerup 落在屏幕同一坐标上，此时命中的已经是**另一行**的控件。
（真的点错过删除按钮，所以 `useDismiss` 里留了一段「必须吞掉这次点击」的补丁。）
面板由 Radix Popover 定位到上层，不占布局，那段补丁连同行内编辑态一起删掉了。

行上只保留「这一条是什么」：状态、标题、进度徽章、关联徽标、时间范围、备注、项目、附件。
「改这一条」的动作全部收进面板 —— 一行五个按钮减到两个（项目与附件是信息入口，不是动作）。

## 怎么用

| 操作 | 结果 |
|---|---|
| 点标题 | 开面板，光标直接落在标题上 |
| 回车 | 落地标题并关面板 |
| Esc | 放弃标题/备注的改动并关面板 |
| 点面板外 | 落地改动并关面板 |
| 日期 | 月历里点一天改期；今天 / 明天两个快捷键。**连同子任务一起挪**（`moveTaskToDate`） |
| 时间 | 原有的时间段选择器，改完即生效 |
| 关联 / 项目 / 附件 | 原有的选择器与内联附件列表 |
| 添加子任务 | 面板底部输入，回车即落库（多行粘贴仍会拆成多条） |
| 删除 | 面板右下角，走原有的二次确认 |

标题与备注是草稿，**提交时才写一次**：逐字符 `updateTask` 会把撤销栈灌满，
撤销就变成逐字回退。其余字段一次改动就是一个动作，直写。

这一天空了以后，那句「这一天还没有计划」本身就是入口，点一下光标回到快速添加框。

## 边界

- 改期是**跨日期搬家**，不是「任务带一个日期字段」：日期就是它的存储位置（`days[date]`），
  所以没有「清除日期」，想换天就点另一个日子，想撤就 Ctrl+Z。
- 看板视图的卡片仍是就地改名（它本来就只有标题可改），纸片窗口走自己的行组件，
  两者共用同一份数据，互不影响。
