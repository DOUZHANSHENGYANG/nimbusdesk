# 首页三视图：总览 / 清单 / 脉络

首页（`/`）有三个视图，右上角切换。版式与项目页总览共用 `src/components/ui/dashboard.tsx` 里的数字格、卡片与分段条，两页的比例、字号、间距是同一套。

## 总览（默认落点）

一屏摊开今天要动的四件事，每张卡只回答一个问题，卡内只放“能直接动手”的东西：

| 卡片 | 内容 | 点一条会怎样 |
|---|---|---|
| 今日计划 | 完成率分段条 + 今日顶层计划（勾选即完成，子任务在主清单里看） | 勾选框写回 `plans`；标题跳 `/plans?date=&task=` |
| 待办工作项 | 未完成工作项按截止日排（无截止日排最后），逾期标琥珀色 | 跳 `/projects?item=` 直接开那一项 |
| 笔记 | 知识库待整理条目 + 相对时间；未连接资料库时给连接入口；“+”是快捷收集 | 跳 `/knowledge`，不在这里做整理动作 |
| 资讯 | 各渠道条目合成一条时间线（按发布时间倒序、同 id 去重）+ 渠道名 | 跳 `/feeds` |

顶上四个数字格：今日计划 `完成/总数`、待办工作项数（附带逾期数）、待整理笔记数、已抓取资讯条目数（附最近抓取时间）。

## 清单与脉络

- **清单**：按开始时间分上午/下午/晚上/未定时的行式清单，逐条勾选与看子任务用它。
- **脉络**：原来的星图（节点 = 计划/收藏/知识/栅栏），默认暂停播放省 GPU，点播放才动。

三个视图都不删功能：总览负责“一眼看清 + 一步进入”，清单负责“逐条动手”，脉络负责“看关系”。

## 验证

- `npm run check:home`：`src/features/home/overview-core.test.mjs` 覆盖待办排序（无截止日排最后）、资讯时间线合并与去重、相对时间粒度。
- `node scripts/check-home-overview-browser.mjs`（先起 Vite，端口 17800）：真组件 + mock 原生边界，验证总览是落点、四个数字格取值、勾选计划写回并让数字格变成 `2/4`、待办与资讯的深链（`/projects?item=…`、`/feeds`）、笔记卡内容与相对时间，以及清单/脉络两个旧视图没被顶掉。
