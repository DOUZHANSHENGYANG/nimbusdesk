# 项目交互与禅道受控回写

2026-10-18，沿用已确认的项目管理路线，在读取与补绑定之后增加普通字段回写和冲突处理。公司地址、账号仍可后续填写。

## 键盘与迭代

- 新建分类弹窗直接聚焦名称，输入后回车保存；中文输入法确认、长按回车不误提交。
- 项目与工作项表单支持单行输入框回车提交，备注内回车仍换行。
- 连续新建不会被前一个弹窗的延迟关闭清空。
- 新建迭代默认两周，显示明确选中状态，日期为本周一至第二周五；可切三周或自定义，编辑已有自定义迭代不重置日期。

## 开启与使用回写

默认保持只读。在“项目管理 → 禅道连接”保存需要允许回写的字段：标题、备注、截止日期。开启选项、修改本地内容及后台同步都不会自动发送。

来源区域显示待发送、字段冲突或结果待核实。打开后按字段查看上次基线、本地内容及远端当前内容；可选择保留本地、采用远端或编辑合并值，先应用选择，再核对本次修改并明确点击发送。采用远端值不会触发写入。

状态、业务分类、本地项目分组、个人迭代、计划、附件、提醒和磁盘目录不会通过此入口写回；启动／完成任务、工时、评论等独立工作流接口保留为后续扩展，不把本地完成勾选当作任意远端状态更新。

## 一致性与恢复

本地内容和待发送意图保存在同一项目模块、同一 SQLite 事务中。schema 3→4 新增精确来源／工作项外键和队列索引，不修改原始 JSON。待发送数据、冲突双方与同步基线保留在备份中；恢复的连接关闭自动同步、清除回写授权并要求重新认证，恢复的外部写入意图转为待核实。

发送前固定已审核的版本，落盘后如合并了其他窗口的新内容则阻止发送，要求重新核对。原生层再次独立校验已保存的字段授权、唯一来源绑定、待发送状态、预期远端值和请求字段值。请求只包含选择的普通字段。

发送前读取远端，远端在比较期间变化时更新冲突界面并使旧选择失效。正常响应后必须读回核对，才确认同步基线。发送期间继续编辑本地内容，会保留新输入并作为后续修改处理。

写入超时、响应不明或读回失败时保留“结果待核实”；禁止盲重试。先刷新，若确认已生效则清理旧意图，若未生效则保留可手动核对重发的记录，若已有其他修改则显示字段冲突。中断发送后重新打开应用也按待核实处理。

**并发边界：**已审阅的公开 API 没有可验证的原子条件更新保证。本实现采用确认、最新读取、最小字段提交和写后核对，仍不能承诺消除服务端先读后写之间的所有竞争窗口。没有真实公司环境时，未验证实际路由、登录策略、权限或云端写入。
