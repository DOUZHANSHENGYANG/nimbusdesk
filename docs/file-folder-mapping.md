# 文件夹映射

文件管理顶部的「映射文件夹」可将本机文件夹创建为一个分类；选择已有分类后，也可以点击「映射此分类」。原来的「绑定磁盘目录」仍可只作为新建文件的位置，不会自动开启同步。

- 映射显示所选文件夹的直接子文件与子文件夹，不递归展开。不会复制或移动原文件。
- 应用运行或驻留托盘时，每 5 秒检查一次；切回应用时也会刷新。分类旁的刷新按钮支持立即刷新。
- 同步成功后，文件管理与该分类的桌面栅格共用更新后的条目。手动添加的条目会保留；相同路径不会重复显示。
- 目录断开、无权限或扫描不完整时保留上次内容，并显示失败状态；重新可用后自动恢复。
- 「映射选项」支持更换目录或解除映射。解除映射只移除自动生成的引用，不删除磁盘文件，也不移除手动添加的条目。
- 映射条目沿用文件管理原有操作；明确执行删除等磁盘操作仍会影响真实文件。

单次完整扫描最多 5,000 个直接子条目、4 MiB 路径与名称数据，扫描间检查 3 秒预算；超过限制不会提交半份结果。系统调用本身在离线网络盘上仍可能等待，后台最多并行扫描两个目录。

Windows 图标按显示尺寸获取，处理旧快捷方式图标的大面积透明留白；未自选图标的快捷方式读取目标程序的图标，并尊重已有的自选图标。提取或解码失败时显示文件类型图标。
