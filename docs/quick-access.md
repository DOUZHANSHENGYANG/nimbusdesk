# 快捷访问目录

文件收纳页工具条最右的「快捷访问」按钮 → 右侧抽屉（`src/features/files/quick-access-drawer.tsx`）。
它管的是**磁盘上的真实文件夹**，和库里的收纳盒不是一回事：盒子是条目，快捷访问是位置。

## 抽屉里能做什么

| 位置 | 动作 |
| --- | --- |
| 顶部「新增绑定目录」 | 弹系统选目录框，选完只显示目录名（取路径最后一段） |
| 行本身 | 点一下在文件管理器里打开这个目录 |
| 复制 | 复制完整路径 |
| 铅笔 | 重新绑定：再选一个目录，替换这一行 |
| 红色垃圾桶 | 删除绑定（只删这一行，不动磁盘） |

数据落在 `useSettings.quickDirs`，只存 `{ id, name, path }`；`name` 由 `quickDirName()` 从路径最后一段取，不另起名字。

## 拖放落点

- 盒子浮层底部的「拖到：」条在「桌面 / 其他盒子」后面列出所有绑定目录（`data-drop-quick`）。
- 拖条目到目录行：文件真的搬过去（`move_fence_entries`），条目路径跟着改；网址没有文件，直接拒绝。
- 从资源管理器把文件拖到抽屉里的行：只搬磁盘文件，不进库。
- 抽屉行与「拖到：」chip 共用同一个属性，指针拖拽与原生拖放都按 `elementFromPoint` 判定落点。

## 验证

```powershell
npm run tauri dev
```

1. 文件收纳 → 快捷访问 → 新增绑定目录（系统选目录框）→ 行上三个按钮分别是复制 / 重新绑定 / 删除；
2. 打开任一盒子 → 底部「拖到：」出现同名 chip；
3. 把条目拖到 chip 上：原路径的位置上没有文件了，条目指向新目录；
4. `npx tsc --noEmit`、`npm run check:i18n`。

浏览器夹具（`src/features/files/fixtures/page.html`）里 `pick_folder` 返回 null，只能看抽屉布局，
绑定/重绑/搬运要在 `npm run tauri dev` 里试。
