# 六个候选方向（S = 17s）

共同输入：`spec.md`。三版统一 1440×900、同一份真实内容。

## A1 · 最佳设计师｜深澤直人（Naoto Fukasawa）· 无意识设计

- 逻辑与来源：深澤直人的「设计要让人不用想就会用」（Without Thought）——界面像日常家电的面板，不解释也知道按哪里。
- 借的是什么：一屏只承载一个决定；形体圆润、材质哑光；按钮按下有实感（2px 实底阴影 + 位移）；装饰为零，层级靠材质与留白；字少而大；标题用宋体（衬线）压手感，正文无衬线。
- 主角素材：数字本身（10 处待修 / 267 篇）做成主角，配一个手绘感的指示范畴。
- 骨架：单列纵向，一屏一件事：状态 → 三张「大按钮卡」→ 最近学到的。
- 胆量花在哪：把「体检报告」整页砍掉，只留三个动作入口，其余藏进展开层。
- form 来自内容的哪里：小白每天真正要做的只有两三件事，所以版式就是一屏两三件事。

## A2 · 最佳设计师｜Dieter Rams（Braun）· 少而准

- 逻辑与来源：Rams 的 ten principles——功能可见、诚实、经久；Braun 面板的刻度与分块。
- 借的是什么：顶部一条「仪表」状态带（数字＋细刻度）；2×2 功能模块，每块一个动作一个数字；灰阶分层（三档灰，不用彩色）；直角、发丝线、精确对齐。
- 主角素材：仪表刻度与数字；程序化材质（CSS 细线、刻度尺）。
- 骨架：仪表带 + 2×2 模块网格 + 底部一行脚注。
- 胆量花在哪：整页只有一种颜色（暖白）和一种灰，靠位置和刻度说话。
- form 来自内容的哪里：这一页本质是「读数 + 操作」，像面板而不是文档。

## B1 · 现实参照｜Bear（bear.app）· 深色三栏

- 逻辑与来源：Bear 的 Mac 版三栏（截图 `refs/notes-apps-1.jpg`，亲眼看过）。左侧图标＋文字分类、中间笔记卡（左色条＋预览）、右侧阅读区。
- 借的是什么：**深色侧栏 + 浅色列表与阅读区**（Bear 的原样，不是全深色）；分类用「图标＋动词短语＋数字」而不是术语；中栏每条带一行「为什么」；选中行左侧 3px 色条；右栏永远解释当前条目并能直接动手。
- 主角素材：真实笔记标题与摘要。
- 骨架：三栏（分类 / 条目 / 详情），永久可见，不要弹窗。
- 胆量花在哪：右栏做成「解释器」——把每条问题翻译成一句人话 + 一个按钮。
- form 来自内容的哪里：知识库是「一堆条目 + 每条要判断」，三栏正是条目工作台。

## B2 · 现实参照｜Craft（craft.do）· 卡片首页

- 逻辑与来源：Craft 的 All Docs 首页（截图 `refs/board-2.jpg`，亲眼看过）：侧栏 + 彩色文档卡片网格。
- 借的是什么：大卡片入口（每张卡片一个主题、一句现状、一个动作）；卡片带色相区分但饱和度低；首页像书架不像报表。
- 主角素材：卡片色块 + 真实笔记标题。
- 骨架：顶栏 + 两列大卡片（要修 / 待归档）+ 下方「最近笔记」横排。
- 胆量花在哪：每张卡片是一个"小世界"（有插图位、有进度），点击进入展开层。
- form 来自内容的哪里：知识库有四个互不相干的活儿，卡片是最直白的并列方式。

## C1 · 秒数轮盘｜网页 #18 Gallery Dark · 内容至上

- 逻辑与来源：抽到网页风格 #18「深色画廊裱框」（参考 Glass / 美术馆暗房）。
- 借的是什么：内容独占视口、UI 退到边缘；近黑底 + 极淡灰小字注脚；一次只给一种信息；边框与卡片全部取消，靠留白与字号分层。
- 主角素材：笔记标题本身（大字号列表）。
- 骨架：顶部一条细状态带（不抢戏）+ 主体笔记流（按区域分组）+ 右侧窄抽屉放要修清单。
- 胆量花在哪：把体检结果缩成一条 28px 高的状态带，其余全给内容。
- form 来自内容的哪里：知识库的价值在里面的内容，不在体检分数。

## C2 · 秒数轮盘｜东亚 #6 香港街招 · 竖排招牌

- 逻辑与来源：抽到东亚风格 #6「香港街招与招牌」。
- 借的是什么：每个功能区是一块**招牌**：竖排粗黑标题 + 纯色底 + 奶白细边 + 硬投影；招牌之间层层叠压；信息密但边界极清楚。
- 主角素材：字与色块（招牌本身）。
- 骨架：左侧竖排招牌列（待修/待归档/经验/找一篇）+ 右侧当前招牌的内容墙。
- 胆量花在哪：整页做成一面墙，四个入口像四块灯箱。
- form 来自内容的哪里："知识库"本来就是个店面，四个功能区就是四块牌子；适合中文竖排。
