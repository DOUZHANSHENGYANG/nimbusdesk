## 用户原话

（"所" 应为 "所以"，按上下文理解为：按我的推荐走，并出浅色磨砂版、配色按现役主题。）

## 采纳方案

**D · 浅色磨砂（A 的骨架 + B 的密度）** — `D-light-frosted.html`

- 材质：浅色三层（窗 white .84 / 面 white .56 + 发丝线 / 内嵌 gray .045），颜色全部走 `--pr-mat-*`、`--pr-gray-*`、`--pr-brand-*`
- 密度：统计条 4 块 + 两行式行（标题 + 时间/子任务/分类），行高 34；资讯页左列表 + 右热榜
- 文字层级：正文 gray-850 / 次要 gray-700 / 三级 gray-600（10px 小字也不用 gray-500，避免掉到 4.5:1 以下）
- 五页：搜索 / 计划待办 / 收集 / 日历 / 资讯，全部在卡片内完成；齿轮带 ↗ 是唯一跳主窗口入口

## 实测

| 项 | 值 |
|---|---|
| 卡片 | 660 × 591（五页等高，切页不跳） |
| 内容溢出 / 横向溢出 | 0 / 0 |
| 控制台错误 | 0 |
| 卡片底 vs 壁纸亮度 | 233 / 72（2x 取样，差 161） |

壁纸改用中暗黄昏（0.40 → 0.20），浅色卡片才浮得起来；原来的浅蓝渐变与卡片同亮度，等于没有边界。
